# Capacity-Oriented RIS Placement Optimization in Indoor 6G Networks via Flower Pollination Algorithm

Reference implementation for the optimal placement of a **Reconfigurable
Intelligent Surface (RIS)** in an indoor multi-transmitter scenario with
line-of-sight (LOS) blockage. A single RIS is positioned on the lateral walls of
an asymmetric 3D room to maximize a capacity-oriented fitness (mean and
worst-case spectral efficiency) under a **multi-transmitter SINR** model with
**geometric occlusion**. The placement is solved with the **Flower Pollination
Algorithm (FPA)** and the cascaded RIS channel is generated by the **SimRIS_v18**
engine.

**Scenario summary:** 2 transmitters · multi-Tx SINR (server + interferer) ·
2 occluding obstacles · 1 RIS · FPA placement. `N ∈ {64, 256}` denotes the RIS
element count of the *same* surface (two configurations), not two distinct RISs.

> Code-only repository (no figures/data/logs committed; see `.gitignore`). All
> artifacts are regenerated by running the scripts.

## 1. System model

### 1.1 Geometry

Asymmetric room of dimensions `Lx × Ly × Lz = 75 × 50 × 3.5` m. Two single-antenna
access points (Tx) are wall-mounted at asymmetric heights/ordinates:

- `Tx1 = (0, 15, 2.5)` (West wall, southern band);
- `Tx2 = (75, 40, 2.5)` (East wall, northern band).

`U = 96` user equipments (UEs) are drawn uniformly at random with a fixed seed at
height `z = 1.0` m, rejecting samples inside any obstacle footprint, within
`margem = 2.0` m of the walls or `dist_min_tx = 3.0` m of either Tx
(`gera_usuarios_cenarioB.m`).

Two cuboid obstacles ("screens") are modeled as axis-aligned bounding boxes (AABB),
each with top `z = 2.4` m and penetration loss `L_obs = 30` dB:

- Obstacle 1 (in front of Tx1): `x∈[16,19], y∈[4,30]`;
- Obstacle 2 (in front of Tx2): `x∈[56,59], y∈[20,46]`.

Since the obstacle tops (2.4 m) sit below both the Tx (2.5 m) and the RIS feasible
height (`z ≥ 2.6` m), the **direct** path Tx→Rx (Rx at 1.0 m) is attenuated while
the **Tx→RIS** path passes above the screens unobstructed — the geometric premise
that motivates RIS deployment.

### 1.2 Geometric occlusion

For any link `P₁→P₂`, the excess loss is the sum of penetration losses of all AABBs
intersected by the segment (`occlusao_att_dB.m`):

```
L(P₁,P₂) = Σ_k  L_obs,k · 1[ segment P₁P₂ pierces box k ]   [dB]
```

Intersection uses the **slab method** over the parametric segment `t∈[0,1]`; a
positive-length crossing is required (a corner/edge touch, `t_min = t_max`, does not
block). The corresponding linear amplitude factor is `a = 10^(−L/20)`.

### 1.3 Cascaded RIS channel

For each UE, `SimRIS_v18` returns the Tx→RIS channel `H ∈ ℂ^{N×1}`, the RIS→Rx
channel `G ∈ ℂ^{N×1}` and the direct channel `D ∈ ℂ` (mmWave, `f = 28` GHz,
indoor environment `Env = 1`, `ArrayType = 2`, `Nt = Nr = 1`). Occlusion is applied
per link in real coordinates:

```
H̃ = a_H · H ,   G̃ = a_G · G ,   D̃ = a_D · D
```

The end-to-end channel under RIS phase profile `θ ∈ ℝ^N` is

```
C(θ) = G̃ᵀ diag(e^{jθ}) H̃ + D̃ .
```

The RIS aligns to its **server** (the stronger Tx) in closed form, co-phasing the
reflected and direct contributions:

```
θ* = ∠D̃ − (∠H̃ + ∠G̃)   (element-wise).
```

> **Mirrored frame for Tx2.** `SimRIS_v18` assumes the source on the West wall, so
> Tx2 (East wall) is evaluated in an x-mirrored frame (`x ↦ Lx − x`) applied to Tx2,
> RIS and Rx **only to call the engine**. Occlusion is always computed in real room
> coordinates. Both side walls (South `y=0`, North `y=Ly`) map to SimRIS Scenario 1.

### 1.4 Multi-Tx SINR and spectral efficiency

The RIS serves the stronger Tx; the other Tx is an **interferer** whose cascaded
channel is re-evaluated under the **same** server phase profile `θ*` (the RIS cannot
simultaneously optimize both links). With `ρ = P_t / P_n = 10^((30−(−80))/10) = 10^{11}`:

```
γ_u = ρ |C_sig|²  /  ( ρ |C_int|² + 1 )            (SINR)
SE_u = log₂(1 + γ_u)                               [bps/Hz]
```

where `C_sig = C(θ*)` of the server and `C_int = G̃_intᵀ diag(e^{jθ*}) H̃_int + D̃_int`
of the interferer. The unit additive term normalizes the noise (signal and
interference share `P_t`, noise shares `P_n`, so `γ_u` is unit-independent). Each UE
is averaged over `R = 20` Monte Carlo channel realizations.

**Baseline (no RIS):** direct paths only; server = stronger direct, the other becomes
interferer, `γ_u^{BL} = ρ·max(|D̃₁|²,|D̃₂|²) / (ρ·min(|D̃₁|²,|D̃₂|²) + 1)`.

## 2. Optimization problem

Let `p = (x, y, z)` be the RIS position. The placement problem is

```
maximize_p   f(p) = α · mean_u SE_u(p) + (1−α) · P₅{ SE_u(p) }
subject to   p ∈ 𝒲  (South or North wall),   z ∈ [2.6, 3.0] m
```

where `P₅{·}` is the 5th-percentile (worst-served) spectral efficiency over the
UEs, with `α = 0.7`, balancing aggregate throughput and cell-edge (fairness) SE. The
feasible set `𝒲` is the union of the two side walls; candidates are projected onto
the nearer wall by `snap_lateral` (sets `y∈{0, Ly}`). The lower bound `z ≥ 2.6` m
enforces an unobstructed Tx→RIS path.

### 2.1 Flower Pollination Algorithm (`fpa_cenarioB.m`)

| Symbol | Meaning | Value |
|---|---|---|
| `n` | population (flowers) | `20` |
| `p_switch` | global/local switch probability | `0.8` (`rand > p` ⇒ global, Lévy) |
| `d` | search dimension `(x,y,z)` | `3` |
| `T` | iterations | `300` |
| `γ` | step scaling | `0.1` |
| `β` | Lévy exponent | `1.5` (`σ ≈ 0.6970`) |
| `N` | RIS elements (two runs) | `{64, 256}` |

Global pollination (biotic, Lévy flight):
`x_i ← x_i + γ · L(β) · (x_i − g*)`, with Lévy step
`L = u / |v|^{1/β}`, `u ~ 𝒩(0, σ²)`, `v ~ 𝒩(0,1)`,
`σ = [ Γ(1+β) sin(πβ/2) / ( Γ((1+β)/2) β 2^{(β−1)/2} ) ]^{1/β}`.

Local pollination (abiotic): `x_i ← x_i + ε · (x_j − x_k)`, `ε ~ 𝒰(0,1)`, `j,k`
random. After each move the candidate is `snap_lateral`-projected; fitness is
evaluated with `parfor`. The incumbent `g*` and per-iteration best are logged to
`progresso_cenarioB.csv`.

### 2.2 Computational cost

Per fitness evaluation: `U · R · 2 = 96 · 20 · 2 = 3840` `SimRIS_v18` calls (two Tx).
Per RIS size: `(1 + T)·n = 6020` evaluations ⇒ `≈ 2.31 × 10⁷` engine calls per `N`
(both Tx). A parallel pool is strongly recommended (`orquestrador_cenarioB.m`).

## 5. Reference results

Optimal RIS placement per `N` (both converge to the **North** wall, `y = 50`):

| N | Position `(x, y, z)` [m] | Fitness `f(p)` |
|---|---|---|
| 64  | `(59.2, 50.0, 3.0)` | `1.9382` |
| 256 | `(56.2, 50.0, 3.0)` | `2.3551` |

Per-user spectral efficiency (multi-Tx SINR, single realization, 96 UEs):

| Group | min | median | mean | max |
|---|---|---|---|---|
| Baseline (no RIS) | 0.014 | 1.682 | 2.589 | 11.785 |
| RIS `N=64`  | 0.024 | 1.703 | 2.690 | 11.785 |
| RIS `N=256` | 0.304 | 1.971 | 3.122 | 11.314 |

The largest gains appear at the **lower tail** (worst-served UEs behind the
obstacles), consistent with the fairness-weighted objective: `N=256` raises the
minimum SE from `0.014` to `0.304` bps/Hz (≈ 22×).
