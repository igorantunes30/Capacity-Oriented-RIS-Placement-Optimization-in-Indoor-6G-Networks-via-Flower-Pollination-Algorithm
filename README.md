# Scenario B — 2 Tx + Interference + 2 Obstacles + 1 RIS (FPA)

**Self-contained** folder with the scenario code: asymmetric 3D room with
**2 transmitters**, a **multi-Tx SINR model (server + interferer)** and
**2 obstacles (screens)** that block the line of sight (LOS). The position of a
**single RIS** is optimized on the side walls (South/North) via **FPA (Flower
Pollination Algorithm)**; the cascaded channel is evaluated by **SimRIS_v18**
(included in this folder).

> **Current configuration:** interference ✅ · 2 obstacles ✅ · FPA ✅ · **1 RIS**
> (not two). The whole codebase assumes a single RIS; `N ∈ {64, 256}` is the
> element count of the same RIS, not two distinct RISs.

> Code-only folder (no PNG/MAT/CSV/logs). All artifacts are regenerated by
> running the scripts.

## 2. What each file does

### Engine
| File | Role | Description |
|---|---|---|
| `SimRIS_v18.m` | engine | Models the RIS channel. Given `(Env, scenario, Freq, ArrayType, N, Nt, Nr, Tx, Rx, RIS)` it returns `[H, G, D]` = Tx→RIS, RIS→Rx and direct Tx→Rx channels. Requires the Communications Toolbox. |

### Optimization core
| File | Type | Description |
|---|---|---|
| `cenarioB_config.m` | function | Returns `cfg` with **all** parameters: room `75×50×3.5`, `Tx1=[0,15,2.5]`, `Tx2=[75,40,2.5]`, radio (`Pt=30 dBm`, `Pn=-80 dBm`), 2 obstacles (30 dB, top `z=2.4`), 96 users (`seed=7`), RIS search space `Lb=[0,0,2.6]`/`Ub=[75,50,3.0]`, `alpha=0.7`. |
| `gera_usuarios_cenarioB.m` | function | Draws `num_users=96` uniform UEs (fixed seed), rejecting points inside the blocker footprint, too close to the walls (`margem`) or to the Tx (`dist_min_tx`). |
| `occlusao_att_dB.m` | function | Extra attenuation (dB) of a segment `P1→P2` crossing 3D AABB boxes (obstacles). Segment-AABB test via the slab method; adds each crossed box's `att_dB`. Corner touch does not block. |
| `calculamediavazao_cenarioB.m` | function | **Heart of the model.** SE per UE via multi-Tx SINR: strongest Tx = server (RIS aligns its phase to it), the other = interferer (same θ + direct). Applies occlusion to `D`, `H`, `G`. Returns `[fitness, taxas, taxas_baseline]`. `fitness = α·mean + (1-α)·min`. |
| `fpa_cenarioB.m` | function | **FPA** (Flower Pollination): Lévy flight (`rand>p`) vs local pollination. `snap_lateral` projects the RIS onto the South (y=0) or North (y=50) wall. `n=20`, `p=0.8`, `N_iter=300`, `β=1.5`. Evaluates via `calculamediavazao` (`parfor`). Logs progress to the CSV. |
| `orquestrador_cenarioB.m` | **ENTRYPOINT** | Runs the optimization for `N∈{64,256}`. Starts `parpool`, generates users, calls `fpa_cenarioB`, saves `progresso_cenarioB.csv`, `resultado_cenarioB.mat`, `usuarios_cenarioB.mat` and convergence curves in `convergencia_cenarioB/`. |

### Metrics (read `convergencia_cenarioB/progresso_cenarioB.csv`)
| File | Description |
|---|---|
| `mc_se_cenarioB.m` | 15 Monte Carlo realizations of SE per UE for Baseline / RIS N=64 / RIS N=256, at the best positions from the CSV. Serial. Output: `mc_se_ues_cenarioB.csv` (one row per realization×UE) + `.mat`. |
| `snr_por_ue_cenarioB.m` | SNR (**no** interference — noise only) per UE, at the optimal N=64/256 positions. Differs from the SINR model: the other Tx does not enter as interferer. Output: `convergencia_cenarioB/snr_por_ue_cenarioB.csv` (linear + dB). |

### Tests without optimization / diagnostics
| File | Description |
|---|---|
| `sanity_cenarioB.m` | Quick validation (short MC, few UEs): checks occlusion in known cases and that the RIS yields gain over the baseline without NaNs. Runs in seconds. |
| `teste_ris_fixa_cenarioB.m` | Evaluates a **fixed low** RIS `[40,0,1.5]` (Tx→RIS path blocked by the obstacles) for N=64/256 vs baseline. Saves `.mat` + boxplot. |
| `teste_ris_alta_cenarioB.m` | Same, but a **high** RIS `[40,0,2.9]` (above the obstacle tops → Tx→RIS free). Direct contrast with the low one. Saves `.mat` + boxplot. |

### Plotting
| File | Description |
|---|---|
| `plots_cenarioB.m` | **All charts in a single file.** Dispatcher + one local function per figure, with shared `pct()`/`plot_box()` helpers. Usage: `plots_cenarioB` (all) or `plots_cenarioB('topologia','cdf_sinr')`. Figures: `topologia`, `topologia_ris`, `topologia_ris_otim`, `convergencia`, `convergencia_N256`, `boxplot_otim_parcial`, `boxplot_sinr`, `boxplot_mc`, `cdf_mc`, `cdf_sinr`. |

> **Path note (`plots_cenarioB.m`):** the functions were unified from scripts that
> lived in 3 different folders; the relative CSV/MAT paths (e.g.
> `convergencia_cenarioB/progresso_cenarioB.csv` vs `../convergencia_cenarioB/...`)
> were kept as in the originals. Adjust `cd`/`csv` inside each function if the data
> lives elsewhere.

## 3. How to run

### Step 1 — Optimization (mandatory; produces the RIS positions)
In MATLAB, with this folder as the current directory:
```matlab
orquestrador_cenarioB
```
Runs the FPA for `N ∈ {64, 256}` (300 iterations each, `rng(1)`). Writes
`progresso_cenarioB.csv`, `resultado_cenarioB.mat`, `usuarios_cenarioB.mat` to
`convergencia_cenarioB/`. **Expensive** — use the parallel pool.

### Step 2 — SE/SINR and SNR metrics (read the CSV from Step 1)
```matlab
mc_se_cenarioB            % 15 MC realizations → mc_se_ues_cenarioB.csv (+ .mat)
snr_por_ue_cenarioB       % SNR, no interf.    → convergencia_cenarioB/snr_por_ue_cenarioB.csv
```

### Step 3 — Charts
```matlab
plots_cenarioB            % generates ALL figures
% or selective:
plots_cenarioB('topologia','convergencia','cdf_sinr')
```

### Quick diagnostics (without optimizing)
```matlab
sanity_cenarioB           % validates occlusion + RIS gain (reduced MC)
teste_ris_fixa_cenarioB   % fixed low RIS  (Tx→RIS blocked)
teste_ris_alta_cenarioB   % fixed high RIS (Tx→RIS free)
```

| Obstacle 1 (in front of Tx1, South band) | blocker | `[16, 19, 4, 30, 0, 2.4, 30 dB]` |
| Obstacle 2 (in front of Tx2, North band) | blocker | `[56, 59, 20, 46, 0, 2.4, 30 dB]` |
| Users | `num_users`/`seed_users` | `96` / `7` |
| RIS search | `Lb` / `Ub` | `[0,0,2.6]` / `[75,50,3.0]` |

**Obstacles**: top at `z=2.4` m. The direct Tx→Rx (Rx at `z=1.0`) **crosses and is
attenuated** by 30 dB; the Tx→RIS path (`z≥2.6`) **passes above, free**.

## 5. Multi-Tx SINR model (`calculamediavazao_cenarioB.m`)

- **Server**: Tx with the largest cascaded `|C|²`. The RIS aligns its phase to it:
  `θ = ang(D) − (ang(H) + ang(G))`.
- **Interferer**: the other Tx — cascaded channel **re-evaluated under the SAME θ of
  the server** + direct path.
- **Occlusion** (`occlusao_att_dB.m`): attenuates `D`, `H`, `G` that cross obstacles
  (segment-AABB, slabs).
- `SINR = (SNR_lin·|C_sig|²) / (SNR_lin·|C_int|² + 1)`, `SE = log2(1 + SINR)`.
- **Baseline** (no RIS): direct paths only; server = strongest direct, the other
  becomes interferer.
- Tx2 (East wall) uses an **x-mirrored frame** (`x → 75−x`) only to *call*
  `SimRIS_v18`; occlusion is always computed in REAL coordinates.

---

## 6. FPA (`fpa_cenarioB.m`)

Called as `fpa_cenarioB([20, 0.8], N, pos_Rx, cfg, csv)`:

| Parameter | Value |
|---|---|
| `n` (population) | `20` |
| `p` (global/local switch) | `0.8` (`rand > p` ⇒ Lévy flight) |
| `d` (dimension) | `3` = `[x, y, z]` |
| `N_iter` | `300` |
| `gamma_step` (γ) | `0.1` |
| `beta` (β, Lévy) | `1.5` (⇒ `σ ≈ 0.6970`) |
| `N_lista` | `[64, 256]` |

The RIS is restricted to the **South (y=0)** / **North (y=50)** walls by
`snap_lateral`. `z ≥ 2.6` guarantees the Tx→RIS path is free above the obstacles.
